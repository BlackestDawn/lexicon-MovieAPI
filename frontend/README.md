# MovieAPI Frontend

React + TypeScript SPA for [MovieAPI](../README.md), built with [Next.js](https://nextjs.org). This is an early skeleton — it renders a static overview page and isn't wired to the backend API yet.

See the [root README](../README.md) for what the API does, its endpoints, and how to run the backend.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it. Edit `src/app/page.tsx` to change the page — it hot-reloads.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
